This repository hosts the **Manifesto of the Unfiltered Truth**, a call for justice, climate action, and the recognition of neurodiversity as a vital lens for seeing reality.

## 🤝 How to Add a Translation

We want this message to reach as many people as possible. To add a new language:

1.  **Fork** this repository.
2.  **Copy** `en.html` and rename it to your language code (e.g., `es.html` for Spanish, `ar.html` for Arabic).
3.  **Translate** the content within the `<main>` tag and the `<title>`.
4.  **Update the navigation** (`<nav>` section) in **all** HTML files to include a link to your new translation.
5.  **Submit a Pull Request**.

## 🎨 Style
The project uses a simple, responsive CSS file (`style.css`) to maintain a consistent and impactful look across all languages. The stylesheet includes support for Right-to-Left (RTL) languages like Arabic and CJK fonts for Chinese.
