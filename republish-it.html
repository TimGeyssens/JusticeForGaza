Informazioni su questo progetto

Questo progetto è nato dal rifiuto di rimanere in silenzio. È uno sforzo decentralizzato per documentare l'intersezione tra diritti umani, neurodiversità e sistemi globali di sfruttamento che traggono profitto dalla guerra e dall'ecocidio. Poiché la verità è spesso bersaglio della censura, questo sito è progettato per essere facilmente copiato (mirror) e ripubblicato da chiunque, ovunque.

Resistenza alla censura: come creare un mirror

Se questo sito viene rimosso o bloccato, puoi ospitare la tua copia in pochi minuti. Il sito è costruito con semplici HTML e CSS: non sono richiesti database o server complessi.

1. Clona il codice sorgente

Puoi clonare l'intero progetto usando Git:

git clone https://github.com/TimGeyssens/JusticeForGaza.git

2. Scarica come ZIP

Vai al repository GitHub, clicca sul pulsante verde "Code" e seleziona "Download ZIP". Decomprimi i file sul tuo computer.

3. Ospitalo ovunque

  • GitHub Pages: Carica i file in un nuovo repository e abilita "Pages" nelle impostazioni.
  • Netlify/Vercel: Trascina semplicemente la cartella nelle loro interfacce web per l'hosting gratuito.
  • Server locale: Esegui python3 -m http.server nella cartella per visualizzarlo localmente.
"La verità non appartiene a un singolo dominio. Appartiene alle persone. Crea un mirror di questo sito, condividi i file e mantieni vivo il messaggio."
