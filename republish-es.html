Acerca de este proyecto

Este proyecto nació de la negativa a permanecer en silencio. Es un esfuerzo descentralizado para documentar la intersección de los derechos humanos, la neurodiversidad y los sistemas globales de explotación que se benefician de la guerra y el ecocidio. Debido a que la verdad suele ser blanco de la censura, este sitio está diseñado para que cualquiera, en cualquier lugar, pueda reflejarlo y republicarlo fácilmente.

Resistencia a la censura: cómo reflejar

Si este sitio es retirado o bloqueado, puedes alojar tu propia copia en minutos. El sitio está construido con HTML y CSS simples; no se requieren bases de datos ni servidores complejos.

1. Clonar el código fuente

Puedes clonar todo el proyecto usando Git:

git clone https://github.com/TimGeyssens/JusticeForGaza.git

2. Descargar como ZIP

Ve al repositorio de GitHub, haz clic en el botón verde "Code" y selecciona "Download ZIP". Descomprime los archivos en tu computadora.

3. Alójalo en cualquier lugar

  • GitHub Pages: Sube los archivos a un nuevo repositorio y habilita "Pages" en la configuración.
  • Netlify/Vercel: Simplemente arrastra y suelta la carpeta en sus interfaces web para alojamiento gratuito.
  • Servidor local: Ejecuta python3 -m http.server en la carpeta para verlo localmente.
"La verdad no pertenece a un solo dominio. Pertenece al pueblo. Refleja este sitio, comparte los archivos y mantén vivo el mensaje."
