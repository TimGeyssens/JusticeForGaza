Inteligencia Colectiva

Este manifiesto es un recurso vivo. Para contrarrestar verdaderamente el sistema del 1%, debemos agrupar nuestros conocimientos, estadísticas y perspectivas. Si tienes una idea para una nueva página, un video impactante o datos que deban salir a la luz, queremos saber de ti.

Cómo Contribuir

  • GitHub Issues: La mejor manera de sugerir contenido nuevo es abriendo un issue en nuestro repositorio de GitHub. Puedes describir tu idea o proporcionar enlaces a recursos.
  • Pull Requests: Si tienes inclinaciones técnicas, puedes hacer un fork del repositorio, agregar tu contenido tú mismo y enviar un Pull Request. Esto garantiza que el sitio siga siendo descentralizado y resistente.
  • Compartir Recursos: Buscamos datos sobre extracción sistémica, historias personales de resistencia y videos educativos que eviten los filtros de los medios corporativos.
"La verdad es un rompecabezas que debemos resolver juntos. Cada dato, cada historia compartida y cada nueva perspectiva hace que la imagen sea más clara."
