关于本项目

这个项目源于拒绝保持沉默。这是一项去中心化的努力，旨在记录人权、神经多样性以及从战争和生态灭绝中获利的全球剥削体系的交集。由于真理经常成为审查的目标，本网站旨在让任何人在任何地方都能轻松镜像和重新发布。

关于创作者

今天，我在技术背景与对社会关怀及教育的深厚承诺之间寻求平衡。我向来自不同背景的研究生教授艺术，并在一家儿童医疗中心工作。尽管取得了职业成就，但目前的经济体系迫使我必须付出 140% 的努力才能生存，过着月光族的生活。我还经营着一家小型独立唱片公司 Pool Needle，作为在企业控制之外支持文化的一种方式。

在职业层面，我始终追随对技术和社区的热情。我曾担任过多个高级企业职位，但我亲眼目睹了“狗屁工作”（Bullshit Jobs）的问题：管理层冗余，以及那些不创造任何价值的人通过剥削他人的劳动来攫取利润。我曾连续多年荣获 Umbraco MVP 称号，并成为开源领域的知名人物。我见证并帮助这家当时只有 3 人的公司成长为现在拥有数十名员工的规模——尽管我也目睹了它在企业化过程中失去了灵魂。

我从未喜欢过等级制度；我不擅长运动，而且在小学时经常被欺负。这些经历，加上 30 岁时诊断出的双相情感障碍和童年时期的选择性缄默症，让我对这个“神经典型”系统有了独特的视角。我花了 43 年才充分意识到这台机器是多么腐败和不公。 我一直是一个质疑“为什么”的人——我们为什么要活着？为什么有些人拥有一切，而另一些人却一无所有？我们都认识某人，或者有家人患有癌症或心理健康问题。我逐渐意识到，这些不仅仅是个人悲剧；它们是我们所生活的系统所创造和维持的问题。

我从伟大的哲学家那里汲取了巨大的力量，并经常觉得绝大多数人都生活在“洞穴”中，看着墙上的影子，从未进入过原始现实的光明之中。音乐和舞蹈是我重要的宣泄方式——这些节奏能够避开系统的噪音。我有两个孩子，为了他们，也为了世界上所有的孩子，我拒绝保持沉默。

抗审查：如何镜像

如果此网站被关闭或封锁，您可以在几分钟内托管自己的副本。该网站使用简单的 HTML 和 CSS 构建——不需要复杂的数据库或服务器。

1. 克隆源代码

您可以使用 Git 克隆整个项目：

git clone https://github.com/TimGeyssens/JusticeForGaza.git

2. 下载为 ZIP

前往 GitHub 仓库，点击绿色的“Code”按钮，然后选择“Download ZIP”。在您的计算机上解压缩文件。

3. 在任何地方托管

  • GitHub Pages： 将文件上传到新仓库，并在设置中启用“Pages”。
  • Netlify/Vercel： 只需将文件夹拖放到它们的 Web 界面即可免费托管。
  • 本地服务器： 在文件夹中运行 python3 -m http.server 即可在本地查看。
