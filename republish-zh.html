关于本项目

这个项目源于拒绝保持沉默。这是一项去中心化的努力，旨在记录人权、神经多样性以及从战争和生态灭绝中获利的全球剥削体系的交集。由于真理经常成为审查的目标，本网站旨在让任何人在任何地方都能轻松镜像和重新发布。

抗审查：如何镜像

如果此网站被关闭或封锁，您可以在几分钟内托管自己的副本。该网站使用简单的 HTML 和 CSS 构建——不需要复杂的数据库或服务器。

1. 克隆源代码

您可以使用 Git 克隆整个项目：

git clone https://github.com/TimGeyssens/JusticeForGaza.git

2. 下载为 ZIP

前往 GitHub 仓库，点击绿色的“Code”按钮，然后选择“Download ZIP”。在您的计算机上解压缩文件。

3. 在任何地方托管

  • GitHub Pages： 将文件上传到新仓库，并在设置中启用“Pages”。
  • Netlify/Vercel： 只需将文件夹拖放到它们的 Web 界面即可免费托管。
  • 本地服务器： 在文件夹中运行 python3 -m http.server 即可在本地查看。
