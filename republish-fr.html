À propos de ce projet

Ce projet est né d'un refus de se taire. Il s'agit d'un effort décentralisé pour documenter l'intersection des droits de l'homme, de la neurodiversité et des systèmes mondiaux d'exploitation qui profitent de la guerre et de l'écocide. Parce que la vérité est souvent la cible de la censure, ce site est conçu pour être facilement mis en miroir et republié par n'importe qui, n'importe où.

Résistance à la censure : Comment mettre en miroir

Si ce site est supprimé ou bloqué, vous pouvez héberger votre propre copie en quelques minutes. Le site est construit avec du simple HTML et CSS—aucune base de données ou serveur complexe n'est requis.

1. Cloner le code source

Vous pouvez cloner l'intégralité du projet via Git :

git clone https://github.com/TimGeyssens/JusticeForGaza.git

2. Télécharger en ZIP

Allez sur le dépôt GitHub, cliquez sur le bouton vert "Code" et sélectionnez "Download ZIP". Décompressez les fichiers sur votre ordinateur.

3. Hébergez n'importe où

  • GitHub Pages : Téléchargez les fichiers vers un nouveau dépôt et activez "Pages" dans les paramètres.
  • Netlify/Vercel : Glissez-déposez simplement le dossier dans leurs interfaces web pour un hébergement gratuit.
  • Serveur Local : Exécutez python3 -m http.server dans le dossier pour le visualiser localement.
"La vérité n'appartient pas à un seul domaine. Elle appartient au peuple. Mettez ce site en miroir, partagez les fichiers et gardez le message vivant."
