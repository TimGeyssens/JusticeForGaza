Sobre o Criador

Venho de uma humilde família trabalhadora da Bélgica — pessoas com corações de ouro que eram frequentemente desprezadas pelas classes "superiores". Durante a semana, passava a maior parte do tempo com os meus avós porque os meus pais tinham de trabalhar longas horas apenas para ganhar o pão. A nível profissional, segui sempre a minha paixão pela tecnologia e pela comunidade. Fui honrado como Microsoft MVP durante vários anos e tornei-me uma figura conhecida no mundo do código aberto, particularmente na comunidade Umbraco, onde criei vários pacotes populares.

Hoje, equilibro o meu percurso técnico com um profundo compromisso com o setor social, ensinando e trabalhando no MPC Sint-Franciscus (um centro médico pediátrico). Apesar das minhas conquistas profissionais, o atual sistema económico obriga-me a trabalhar 140% apenas para sobreviver, vivendo mês a mês. Também giro uma pequena editora independente, a Daft Records, como forma de apoiar a cultura fora do controlo corporativo.

Nunca fui fã de hierarquias; nunca fui bom em desportos e fui frequentemente alvo de bullying na escola primária. Estas experiências, combinadas com um diagnóstico de transtorno bipolar aos 30 anos e mutismo seletivo na infância, deram-me uma perspetiva única sobre o sistema "neurotípico". Levei 43 anos para perceber plenamente quão corrupta e injusta esta máquina realmente é. Tenho dois filhos e, por eles — e por todas as crianças do mundo — recuso-me a ficar em silêncio.

Sobre este projeto

Este projeto nasceu da recusa em permanecer em silêncio. É um esforzo descentralizado para documentar a interseção dos direitos humanos, da neurodiversidade e dos sistemas globais de exploração que lucram com a guerra e o ecocídio. Como a verdade é frequentemente alvo de censura, este site foi projetado para ser facilmente espelhado e republicado por qualquer pessoa, em qualquer lugar.

Resistência à censura: como espelhar

Se este site for retirado ou bloqueado, você pode hospedar sua própria cópia em minutos. O site foi construído com HTML e CSS simples — não são necessários bancos de dados ou servidores complexos.

1. Clonar o código-fonte

Você pode clonar o projeto inteiro usando Git:

git clone https://github.com/TimGeyssens/JusticeForGaza.git

2. Baixar como ZIP

Vá ao repositório GitHub, clique no botão verde "Code" e selecione "Download ZIP". Descompacte os arquivos no seu computador.

3. Hospedar em qualquer lugar

  • GitHub Pages: Faça o upload dos arquivos para um novo repositório e ative o "Pages" nas configurações.
  • Netlify/Vercel: Simplesmente arraste e solte a pasta em suas interfaces web para hospedagem gratuita.
  • Servidor local: Execute python3 -m http.server na pasta para visualizá-lo localmente.
"A verdade não pertence a um único domínio. Pertence ao povo. Espelhe este site, compartilhe os arquivos e mantenha a mensagem viva."
